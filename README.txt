AIRFARE INTELLIGENCE DASHBOARD

1. Install:
   pip install -r requirements.txt

2. In app.py, set DB_CONFIG to match your existing MySQL database.
   Default database name is airfare_db.

3. Run:
   py app.py

4. Open:
   http://127.0.0.1:5000

Uses existing project tables:
cleaned_fares, route_weights, airfare_index, fare_predictions, fare_recommendations.
